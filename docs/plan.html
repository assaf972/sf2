Product usage

GigSynth turns a laptop, mini-PC or Raspberry Pi into a self-contained FluidSynth sound module for live performance. The player loads one shipped SoundFont, assigns its instruments to up to three MIDI keyboards, and layers/splits up to four sounds. Each keyboard has its own Chorus and Delay insert.

Work is organised as Songs → Parts: a Part snapshots the whole rig (per-keyboard sound, volume, pan, pitch, split and effects). On stage the player simply steps Next Part to swap the entire sound and mix in one move. A built-in MP3 player (start/stop/pitch/loop) covers backing tracks.

The same binary runs three ways: the full 3-view desktop UI (Live / Songs / Settings) on Windows, macOS, Linux and Pi 4/5; a 7" touch layout (-mode touch7, focus-one-keyboard so FX knobs stay finger-sized); and a Pi Zero 2 W kiosk (-mode pizero, two-row menu + four live knobs, 61-key part navigation). See the user guide and Pi Zero UI flow.
