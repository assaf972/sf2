GigSynth — Raspberry Pi Provisioning

Turn a flashed Pi into a GigSynth instrument that boots straight into the rig.

One command

The binary ships its own setup assets. Run -provision with your hardware model to write a systemd user service and an install script tailored to that build:

# on the Pi, next to the gigsynth binary
gigsynth -provision gs-61 -provision-out ./setup -sf2 /opt/gigsynth/Live.sf2
# -> wrote ./setup/gigsynth-kiosk.service
# -> wrote ./setup/install.sh
./setup/install.sh        # installs deps + enables autostart

What the install script does

  • Installs the runtime libraries (FluidSynth, rtmidi, ALSA, GL) via apt.
  • Copies the generated gigsynth-kiosk.service into ~/.config/systemd/user/, reloads systemd, enables it, and turns on user lingering so it starts at boot.
  • Leaves commented dtoverlay lines for the audio HAT (HiFiBerry DAC / pisound) to uncomment for your build.
The audio DAC overlay and DSI screen wiring are the operator's hardware step; this flow produces the repeatable software setup. See the full BOM for the hardware per model.
